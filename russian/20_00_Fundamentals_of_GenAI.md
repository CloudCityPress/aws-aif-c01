# Домен 2. Основы генеративного ИИ

Генеративный ИИ сегодня является крупнейшим источником новых ИИ-проектов в большинстве крупных компаний. Домен 2 занимает 24% веса экзамена и служит входной точкой в Домен 3, где рассматривается практическое применение базовых моделей. Главы этого домена формируют концептуальный аппарат для понимания генеративных систем: токены, векторные представления, базовые модели, агентные паттерны и компромиссы между стоимостью и возможностями, которые определяют реальные закупочные решения.

Стратегическое значение этого материала состоит в том, что структура затрат и характер сбоев генеративного ИИ принципиально отличаются от классического машинного обучения. Генеративные системы оплачиваются по токенам, а не по числу предсказаний. Они допускают ошибки-галлюцинации, которые выглядят авторитетно. Они выдают результаты, которые меняются от запуска к запуску даже при одинаковых входных данных. Бизнес-стейкхолдеры, понимающие эти свойства, принимают более взвешенные решения о том, какие задачи стоит решать с помощью генеративного ИИ, а какие лучше оставить другим инструментам.

После завершения этого домена вы сможете определить базовый словарь генеративного ИИ, включая дополнения v1.1: контекстная инженерия, ценообразование на основе токенов и агентный ИИ. Вы сможете перечислить типичные сценарии использования генеративного ИИ (суммаризация, ИИ-ассистенты, перевод, генерация кода, обслуживание клиентов, поиск, рекомендации) и подобрать к каждому подходящий класс моделей. Вы сможете взвешивать преимущества и ограничения генеративного ИИ при оценке бизнес-задачи. А также получите обзор портфеля AWS для создания генеративных приложений: от Amazon Bedrock и Amazon SageMaker JumpStart до Amazon Bedrock AgentCore, Strands Agents, Kiro и Amazon Quick.

Домен напрямую связан с практической работой двумя способами. Во-первых, он даёт язык для участия в дискуссиях по дизайну генеративного ИИ без риска потеряться в жаргоне. Во-вторых, формирует ментальную модель для оспаривания предложений, которые обещают слишком много. Когда вендор или внутренняя команда презентует решение на основе генеративного ИИ, вы будете знать, какие вопросы задать: каков токенный бюджет на взаимодействие, как обрабатываются галлюцинации, какие ограждения перехватывают токсичный вывод, какая часть рабочего процесса агентная, а какая одноразовая, и какой сервис AWS используется в качестве базовой платформы.

Следующие главы разбивают домен на три формулировки задач. Задача 2.1 охватывает базовые концепции генеративного ИИ, включая новый материал по агентному ИИ и протоколу контекста модели (Model Context Protocol). Задача 2.2 рассматривает возможности и ограничения генеративного ИИ с акцентом на галлюцинации, недетерминизм и компромиссы при выборе модели, которые важны для инженерных команд. Задача 2.3 охватывает инфраструктуру и сервисы AWS для создания приложений на основе генеративного ИИ с акцентом на то, как новые сервисы v1.1 дополняют уже устоявшиеся. К концу домена у вас будет система, необходимая для продуктивного участия в любом генеративном ИИ-проекте на AWS.

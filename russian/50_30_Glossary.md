# Глоссарий

В этом глоссарии собраны ключевые термины, встречающиеся в книге. Английские термины, которые переводятся на русский, приведены с русским эквивалентом и кратким определением. Термины категорий "сохраняется в оригинале" (названия сервисов AWS, протоколов, официальных программ сертификации) снабжены пояснением на русском языке.

---

## A

**AgentCore authorization policies** — функция авторизации в Amazon Bedrock AgentCore, определяющая, какие действия, инструменты и внешние конечные точки агент вправе использовать в ходе сеанса.

**AIF-C01** — код экзамена AWS Certified AI Practitioner; охватывает основы ИИ, генеративный ИИ, приложения базовых моделей, ответственный ИИ, безопасность и управление.

**Amazon Athena** — интерактивный сервис запросов AWS, позволяющий анализировать данные в Amazon S3 с помощью стандартного SQL.

**Amazon Aurora** — полностью управляемый реляционный СУБД AWS, совместимый с MySQL и PostgreSQL.

**Amazon Bedrock** — полностью управляемый сервис AWS, предоставляющий доступ к базовым моделям ведущих поставщиков через единый API.

**Amazon Bedrock AgentCore** — набор функций в Amazon Bedrock для создания, развёртывания и управления ИИ-агентами промышленного уровня.

**Amazon Bedrock Agents** — функция Amazon Bedrock для создания агентов, автономно выполняющих многошаговые задачи с вызовом инструментов.

**Amazon Bedrock Guardrails** — слой применения политик в Amazon Bedrock, фильтрующий промпты и ответы по настроенным правилам тем, безопасности, конфиденциальности и заземления.

**Amazon Bedrock Knowledge Bases** — функция Amazon Bedrock, автоматизирующая загрузку, разбивку, векторизацию и поиск документов для RAG-приложений.

**Amazon CloudWatch** — сервис мониторинга и наблюдаемости AWS, собирающий метрики, журналы и события из ресурсов AWS.

**Amazon Comprehend** — сервис обработки естественного языка AWS, выполняющий обнаружение сущностей, классификацию, анализ тональности и извлечение PII из текста.

**Amazon EC2** — Amazon Elastic Compute Cloud; виртуальные серверы AWS по требованию.

**Amazon ECS** — Amazon Elastic Container Service; управляемый сервис оркестрации контейнеров AWS.

**Amazon Kendra** — интеллектуальный поисковый сервис AWS на основе машинного обучения для корпоративного поиска документов.

**Amazon Lex** — сервис AWS для создания разговорных интерфейсов с использованием технологий распознавания речи и понимания естественного языка.

**Amazon Macie** — сервис безопасности данных AWS, использующий машинное обучение для обнаружения, классификации и защиты конфиденциальных данных в Amazon S3.

**Amazon Neptune Analytics** — сервис аналитики графовых данных AWS, поддерживающий запросы по векторным данным на графах.

**Amazon Nova** — семейство базовых моделей AWS в Amazon Bedrock, включая Nova Micro, Nova Lite, Nova Pro и Nova Premier.

**Amazon OpenSearch Service** — полностью управляемый сервис поиска и аналитики AWS, поддерживающий хранение векторных данных для RAG-приложений.

**Amazon Q** — генеративный ИИ-ассистент AWS, оптимизированный для корпоративных задач, разработки и работы с данными.

**Amazon Quick** — семейство лёгких агентных моделей AWS в Amazon Bedrock, оптимизированных для быстрых задач.

**Amazon RDS** — Amazon Relational Database Service; управляемый сервис реляционных баз данных AWS.

**Amazon Rekognition** — сервис компьютерного зрения AWS для анализа изображений и видео.

**Amazon S3** — Amazon Simple Storage Service; объектное хранилище AWS, широко применяемое для хранения обучающих данных и артефактов моделей.

**Amazon SageMaker AI** — полностью управляемый сервис AWS для разработки, обучения и развёртывания моделей машинного обучения.

**Amazon SageMaker Clarify** — функция Amazon SageMaker для обнаружения предвзятости в данных и моделях и получения объяснений с помощью значений SHAP.

**Amazon SageMaker Ground Truth** — сервис разметки данных AWS с поддержкой автоматической разметки и рабочих процессов с участием людей.

**Amazon Textract** — сервис AWS для автоматического извлечения текста и структурированных данных из отсканированных документов.

**Amazon Titan** — семейство базовых моделей AWS в Amazon Bedrock для задач генерации текста, создания векторных представлений и мультимодальных задач.

**Amazon Titan Embeddings** — модели семейства Amazon Titan, преобразующие текст в числовые векторные представления для семантического поиска и RAG.

**Amazon Transcribe** — сервис AWS автоматического распознавания речи, преобразующий аудио в текст.

**Amazon Translate** — нейронный сервис машинного перевода AWS.

**Anthropic Claude** — семейство базовых моделей компании Anthropic, доступных в Amazon Bedrock.

**API (Application Programming Interface)** — программный интерфейс приложения; набор правил, позволяющих программным компонентам взаимодействовать друг с другом.

**Auto Scaling** — функция AWS, автоматически регулирующая количество ресурсов в соответствии с нагрузкой.

**AWS** — Amazon Web Services; облачная платформа Amazon.

**AWS Artifact** — самообслуживаемый портал AWS, где можно скачать сертификаты соответствия требованиям и соглашения AWS, в том числе отчёты SOC и сертификации ISO.

**AWS Audit Manager** — сервис AWS, автоматически собирающий аудиторские доказательства из конфигурации и журналов активности и формирующий отчёты для соответствующих фреймворков.

**AWS Backup** — централизованный сервис AWS для управления резервным копированием и политиками хранения данных.

**AWS Config** — сервис AWS, непрерывно фиксирующий конфигурацию ресурсов и оценивающий их соответствие заданным правилам.

**AWS Glue** — полностью управляемый ETL-сервис AWS с возможностями каталогизации данных.

**AWS Glue Data Catalog** — централизованный репозиторий метаданных AWS, хранящий определения схем и описания датасетов.

**AWS IAM Identity Center** — сервис AWS для централизованного управления доступом к нескольким учётным записям и приложениям.

**AWS Key Management Service (KMS)** — сервис AWS для создания, управления и аудита криптографических ключей, применяемых для шифрования данных.

**AWS Lake Formation** — сервис AWS, упрощающий создание защищённых озёр данных с гранулированным контролем доступа на уровне столбцов и строк.

**AWS Lambda** — сервис вычислений без серверов AWS, выполняющий код в ответ на события.

**AWS Marketplace** — онлайн-каталог AWS для поиска, тестирования и покупки стороннего программного обеспечения.

**AWS PrivateLink** — технология AWS, обеспечивающая частное подключение к сервисам AWS без прохождения через публичный интернет.

**AWS re:Invent** — ежегодная крупнейшая конференция AWS по облачным вычислениям.

**AWS re:Inforce** — ежегодная конференция AWS по безопасности, соответствию требованиям и конфиденциальности.

**AWS re:Post** — управляемое AWS сообщество вопросов и ответов для технических специалистов.

**AWS Secrets Manager** — сервис AWS для безопасного хранения, ротации и доступа к учётным данным, ключам API и другим секретам.

**AWS Security Hub** — сервис AWS, агрегирующий результаты проверок безопасности из нескольких источников в единую панель управления.

**AWS Trusted Advisor** — сервис AWS, проверяющий конфигурации учётных записей по передовым практикам в области затрат, безопасности, производительности и отказоустойчивости.

**AWS Well-Architected Framework** — руководство AWS по проектированию надёжных, безопасных, эффективных и экономичных облачных архитектур.

## B

**Bedrock AgentCore Identity** — компонент Amazon Bedrock AgentCore, управляющий учётными данными, которые агент использует при вызове внешних сервисов, с поддержкой OAuth 2.0 и автоматической ротации.

---

## C

**chain-of-thought (цепочка рассуждений)** — техника промптинга, побуждающая модель явно излагать шаги рассуждения до формулирования окончательного ответа.

**Cohere Embed** — модель создания векторных представлений компании Cohere, доступная в Amazon Bedrock.

---

## D

**DeepLearning.AI** — образовательная организация в сфере ИИ, известная онлайн-курсами по глубокому обучению и машинному обучению.

---

## E

**EU AI Act (Закон ЕС об ИИ)** — регуляторный акт Европейского Союза, классифицирующий ИИ-системы по уровню риска и устанавливающий соответствующие обязательства по соответствию требованиям.

---

## F

**few-shot** — техника промптинга, при которой модели предоставляется несколько примеров задачи в промпте перед запросом ответа.

**foundation model (FM, базовая модель)** — крупная модель, предобученная на обширных данных и пригодная для решения широкого круга задач с минимальной или без дополнительной настройки.

---

## G

**GPU** — Graphics Processing Unit; специализированный процессор, широко применяемый для обучения моделей глубокого обучения и инференса благодаря параллельной архитектуре.

---

## I

**IAM (Identity and Access Management)** — управление удостоверениями и доступом; сервис AWS для контроля того, кто и к каким ресурсам AWS может получить доступ.

**ISO/IEC 42001** — международный стандарт для систем управления ИИ, определяющий требования к созданию, внедрению и непрерывному совершенствованию программ управления ИИ в организации.

---

## K

**Kiro** — ИИ-инструмент AWS для разработки программного обеспечения с поддержкой на основе требований.

---

## M

**Meta Llama** — семейство открытых базовых моделей компании Meta, часть которого доступна в Amazon Bedrock.

**Mistral AI** — европейская компания, разрабатывающая открытые базовые модели; ряд моделей доступен в Amazon Bedrock.

---

## N

**NIST AI RMF** — AI Risk Management Framework Национального института стандартов и технологий; добровольный фреймворк управления рисками ИИ с функциями: Управление, Картирование, Измерение, Реагирование.

---

## O

**OAuth 2.0** — открытый стандарт делегирования авторизации, широко применяемый для предоставления приложениям ограниченного доступа к ресурсам от имени пользователя.

**one-shot** — техника промптинга, при которой в промпте перед запросом ответа приводится единственный пример.

---

## P

**personally identifiable information (PII, персональные данные)** — любая информация, позволяющая прямо или косвенно идентифицировать конкретного человека: имена, адреса, идентификационные номера.

**pgvector** — расширение PostgreSQL, добавляющее поддержку хранения и поиска по векторным представлениям; поддерживается Amazon RDS и Amazon Aurora.

**Principal Solutions Architect** — должность старшего технического архитектора в AWS, специализирующегося на проектировании облачных решений для клиентов.

---

## R

**RAG (retrieval-augmented generation, генерация с дополнением на основе извлечения)** — архитектурный паттерн, при котором модель получает доступ к релевантным документам из внешнего хранилища в момент запроса и включает их в контекст, снижая галлюцинации.

---

## S

**Stability AI** — компания, специализирующаяся на диффузионных моделях для генерации изображений; часть моделей доступна в Amazon Bedrock.

**Strands Agents** — SDK AWS с открытым исходным кодом для создания ИИ-агентов, определяемых моделью.

---

## T

**TLS** — Transport Layer Security; криптографический протокол, обеспечивающий шифрование данных при передаче между клиентом и сервером.

**top-k** — параметр инференса, ограничивающий выборку следующего токена топ-k наиболее вероятными кандидатами.

**top-p** — параметр инференса (ядерная выборка), ограничивающий выборку наименьшим множеством токенов, совокупная вероятность которых достигает p.

---

## V

**VPC (Virtual Private Cloud, виртуальное частное облако)** — изолированная виртуальная сеть в AWS, в которой развёртываются ресурсы с полным контролем над адресным пространством, подсетями и правилами доступа.

---

## Z

**zero-shot** — техника промптинга, при которой задача задаётся модели без каких-либо примеров: модель должна выполнить её, опираясь исключительно на свои предобученные знания.

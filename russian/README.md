## Об этом издании

Полное учебное руководство, выстроенное по структуре экзамена и написанное для бизнес-профессионалов: аналитиков, руководителей проектов, продакт-менеджеров и ИТ-специалистов, которым нужно рабочее понимание ИИ и генеративного ИИ на AWS без погружения в низкоуровневые детали реализации.

Каждая глава следует структуре пяти разделов и четырнадцати тем из руководства к экзамену V1.1, поэтому время на изучение материала напрямую соотносится с тем, что оценивается на экзамене.

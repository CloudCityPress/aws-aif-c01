# Домен 5. Безопасность, соответствие требованиям и управление ИИ-решениями

Домен 5 — это операционный и регуляторный тыл для всего остального материала книги. Он занимает 14% экзамена, столько же, сколько Домен 4, однако его практическое значение для развёрнутой ИИ-системы сопоставимо со значением тормозов в автомобиле. Без него вся остальная система опасна вне зависимости от того, насколько хорошо она работает.

Стратегическое значение этого материала резко возросло с переходом от экспериментов к промышленному ИИ. ИИ-системы обрабатывают чувствительные данные, выполняют автономные действия через агентов и генерируют вывод, который клиенты и партнёры получают напрямую. Каждое из этих свойств расширяет как поверхность атаки, так и регуляторную поверхность. Команды безопасности теперь задают те же вопросы об ИИ-нагрузках, которые они всегда задавали о прочих элементах облачной инфраструктуры, плюс новый набор вопросов, специфичных для генеративных и агентных систем.

После завершения этого домена вы сможете определять сервисы и функции AWS, обеспечивающие безопасность ИИ-систем, включая роли и политики IAM, шифрование, Amazon Macie, AWS PrivateLink, а также новые дополнения версии 1.1: Amazon Bedrock AgentCore Identity, Policy in AgentCore и Amazon Bedrock Guardrails. Вы поймёте источниковые ссылки и документирование происхождения данных, включая происхождение данных, каталогизацию данных и Amazon SageMaker Model Cards. Вы будете знать передовые практики безопасной инженерии данных и соображения безопасности и конфиденциальности, специфичные для ИИ: инъекцию промптов, предотвращение утечки данных, фильтрацию и валидацию вывода, журналы аудита для ИИ-взаимодействий и токсичность. Вы будете знать, как использовать заземление через Retrieval Augmented Generation, валидацию вывода и оценку уверенности для обнаружения и снижения галлюцинаций.

Раздел управления домена охватывает сервисы AWS, поддерживающие соответствие требованиям: AWS Config, Amazon Inspector, AWS Audit Manager, AWS Artifact, AWS CloudTrail и AWS Trusted Advisor. Вы сможете описывать стратегии управления данными, которых ожидают аудиторы (жизненные циклы данных, ведение журналов, резидентность, мониторинг, наблюдаемость, хранение), и протоколы управления, обеспечивающие работу этих стратегий на практике (политики, периодичность проверок, стандарты прозрачности, обучение команды и AWS Generative AI Security Scoping Matrix).

Домен связан с вашей работой, поскольку безопасность, соответствие требованиям и управление — это темы, определяющие, дойдёт ли ИИ-прототип до промышленного развёртывания. Модель, которую не одобрит команда безопасности, никогда не увидит реального клиента. Система, которую команда по соответствию требованиям не сможет проаудировать, никогда не попадёт в регулируемую отрасль. Словарь этого домена — то, что вы будете использовать для согласования ИИ-проектов с функциями безопасности и соответствия требованиям в своей организации и для поддержания этого согласования по мере эволюции ИИ-системы.

Следующие главы делят домен на два формулировки задач. Задача 5.1 охватывает методы обеспечения безопасности ИИ-систем, включая новые дополнения версии 1.1 для AgentCore Identity, Bedrock Guardrails и расширенный список соображений конфиденциальности и методов заземления для борьбы с галлюцинациями, специфичных для ИИ. Задача 5.2 охватывает управление и соответствие требованиям, включая AWS Generative AI Security Scoping Matrix и стандартные стратегии управления данными. К концу этого домена у вас будет операционный фреймворк, необходимый для обеспечения безопасности, проверяемости и соответствия требованиям ИИ-системы.

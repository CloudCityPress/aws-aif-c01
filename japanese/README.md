# ビジネスプロフェッショナルのための AWS 認定 AI プラクティショナー
**AWS 試験 AIF-C01 (V1.1) 独学ガイド**

これは無料学習ガイドの**日本語版**です。翻訳は英語原文をもとに Claude Opus 4.7 を用いて行い、技術的正確性と用語の一貫性を著者が確認しました。他の言語：[English](../english/) · [Español](../spanish/) · [Français](../french/) · [Deutsch](../german/) · [Italiano](../italian/) · [Português](../portuguese/) · [Русский](../russian/)。プロジェクト全体の概要については[ルート README](../README.md) をご覧ください。

## 本版について

本書は試験範囲に整合した包括的な学習ガイドで、ビジネスアナリスト、プロジェクトマネージャー、プロダクトマネージャー、IT担当者など、低レベルの実装詳細に踏み込まずに AWS 上の AI と生成 AI に関する実践的な理解を必要とするビジネスプロフェッショナル向けに執筆されています。

各章は試験ガイド V1.1 の5つのドメインと14のタスクステートメントに沿って構成されており、学習時間が試験で評価される内容に直接対応します。

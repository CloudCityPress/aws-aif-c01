# 裏表紙

### 本書について
人工知能はビジネスの運営方法を根本から書き換えており、AWS 認定 AI プラクティショナー試験（V1.1、2026年4月）は初版から大幅に出題範囲が拡大しました。基盤モデル、エージェント型 AI、検索拡張生成（RAG）、そして AWS マネージドエージェントプラットフォームは、わずか1年余りで「興味深い研究テーマ」から「試験の出題範囲」へと移行しました。

本書は AWS 認定 AI プラクティショナー試験に向けた準備をしながら、組織内で AI イニシアティブを推進するための実践的な知識を提供します。AI の選択肢を評価し、エンジニアリングチームと自信を持ってコミュニケーションを取り、適切な問題に対して適切な AWS サービスを選択する方法を学ぶことができます。

- AI、ML、生成 AI のコンセプトと、それぞれがビジネス課題にどのように適合するかをしっかり把握する
- Amazon Bedrock、Amazon Bedrock AgentCore、Strands Agents、Kiro、Amazon Quick を含む最新の試験範囲の AWS サービスを習得する
- 責任ある AI、ガバナンス、および AWS Generative AI Security Scoping Matrix を理解する
- IAM と暗号化から Bedrock Guardrails、プロンプトインジェクション対策まで、AI システムを保護する方法を学ぶ
- AWS 認定 AI プラクティショナー（AIF-C01）試験に自信を持って臨む
- 試験対策だけでなく、実際のプロジェクトに教材を活用する

### 本書の対象読者
本書は、ビジネスアナリスト、IT サポート専門家、マーケティングスペシャリスト、プロダクトマネージャー、および AWS 上の AI を実務で活用するための基礎知識を必要とするビルダー以外の専門家を対象に書かれています。深いコーディング、数学、または ML エンジニアリングの経験は必要ありません。

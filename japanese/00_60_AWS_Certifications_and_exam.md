# AWS 認定と AI プラクティショナー試験

## AWS 認定の概要

AWS 認定は、現代のエンタープライズコンピューティングを支えるクラウドおよび AI テクノロジーの専門知識を検証します。技術的な能力の証明として業界全体で認められており、AWS を効果的に活用するために必要なスキルを身につけたい専門家に向けた体系的なパスとなっています。デジタル変革を進める組織にとって、認定を持つ専門家はプロジェクトの迅速な推進とコストのかかるミスの削減につながる専門知識をもたらします。

メリットは認定資格そのものを超えています。取得者は給与水準の向上、面接機会の増加、そして昇進や挑戦的な業務へのより良いポジションを得やすいと報告しています。[^006001] 認定の背後にあるスキルは実際の課題に対応しており、再認定サイクルによって取得者は AWS ポートフォリオの進化に合わせて知識を最新の状態に保てます。

## AWS 認定パス

AWS はその認定プログラムをファウンデーショナル、アソシエイト、プロフェッショナル、スペシャルティの 4 つのレベルに整理しています。この体系により、専門家は幅広い基礎知識から始め、キャリア目標に沿った専門分野へと段階的に進めます。

AWS 認定のパスは一本の直線ではありません。異なる役割が同じ上級資格に向けて異なる経路をたどります。以下のマップは 3 つの代表的なルートを示しています。

目標が実際のエンジニアリングよりも情報に基づいた意思決定であれば、AI プラクティショナーの後で止めることができます。本番環境で AI エージェントを構築する予定の実務者は、生成 AI デベロッパー - プロフェッショナルに進む前に、少なくとも Solutions Architect - Associate と Machine Learning Engineer - Associate を取得することで多くの恩恵を受けられます。

認定の有効性を維持するために、AWS は 3 年ごとの再認定を要求します。これにより取得者は最新のサービスとベストプラクティスに対応し続けられます。

## AWS 認定 AI プラクティショナー認定

### 概要とポジショニング

AWS 認定 AI プラクティショナー認定は、組織全体での AI リテラシーに対する急速に高まるニーズに対応しています。実装の詳細よりも実践的なビジネス応用を重視しながら、AWS 上の人工知能（AI）、機械学習（ML）、および生成 AI の基礎知識を検証します。

この認定は、AI と隣り合わせで働くが必ずしも自分で構築するわけではないビジネスアナリスト、プロダクトマネージャー、IT サポートスタッフ、およびその他の専門家を対象としています。AI の選択肢を評価し、エンジニアリングチームと効果的にコミュニケーションを取る能力を検証することで、組織がより確かな情報に基づいて AI 機能を採用し、コストのかかるミスを防ぐ力を身につけます。

### 他の AI/ML 認定との違い

AWS AI/ML 認定は現在、明確に階層化されたセットを形成しており、異なる対象者と異なるスキルレベルに対応しています。

```mermaid
flowchart LR
    A[AWS AI/ML 認定] --> B[AI プラクティショナー<br/>ファウンデーショナル]
    A --> C[ML エンジニア<br/>アソシエイト]
    A --> D[データエンジニア<br/>アソシエイト]
    A --> E[生成 AI デベロッパー<br/>プロフェッショナル]
```

*図 0.6.3: AWS AI/ML 認定マップ。各認定はファウンデーショナルレベルのビジネスリテラシーからプロフェッショナルレベルの本番アーキテクチャまで、特定の対象者とスキルの深さを対象としています。*

**Generative AI Developer - Professional** 認定（AIP-C01）は、AWS 上で生成 AI ソリューションを大規模に設計、構築、および運用化する専門知識を検証します。エンドツーエンドで AI システムを担当するアーキテクトおよびシニアエンジニアを対象としています。

**Machine Learning Engineer - Associate**（MLA-C01）は、本番環境で ML モデルを構築、デプロイ、および監視するために必要なスキルを検証します。アプリケーションの ML 側を担当する ML エンジニアと開発者を対象としています。

**Data Engineer - Associate**（DEA-C01）は、AI/ML プロジェクトが依存するデータインフラに焦点を当てています。AI ワークロードを支えるパイプラインとストレージレイヤーを構築・維持するエンジニアを対象としています。

対照的に、**AI プラクティショナー**は基礎とビジネス応用に焦点を当てています。AI/ML ソリューションを使用する専門家向けに設計されており、構築する人向けではありません。ビジネスアナリスト、プロダクトマネージャー、および技術に精通した IT サポートスタッフが主な対象者です。

この 4 段階の階層化は成熟した AI/ML 市場を反映しています。AI の構築、デプロイ、およびガバナンスには、AWS が各レイヤーに個別の認定を設けるほどの専門化されたスキルが求められるようになりました。

## 試験の詳細と構造

### 試験の概要

AWS 認定 AI プラクティショナー（AIF-C01）試験は、90 分で 65 問に解答する形式です。英語、日本語、韓国語、ポルトガル語（ブラジル）、および簡体字中国語で受験できます。最低合格スコアは 100 から 1,000 のスケールで 700 です。

現在の試験バージョンは **V1.1** で、2026 年 4 月 30 日に公開され、約 1 か月後に試験で有効になりました。[^006004] V1.1 では、エージェント型 AI、Amazon Bedrock AgentCore、Strands Agents、Kiro、および Amazon Quick が出題範囲に追加されました。また、Amazon MemoryDB が削除されました。変更内容は十分に大きいため、2026 年中頃以前の準備教材は現在の試験ガイドと照合して確認する必要があります。

```mermaid
flowchart LR
    A[試験内容] --> B[ドメイン 1: AI/ML の基礎 20%]
    A --> C[ドメイン 2: 生成 AI 24%]
    A --> D[ドメイン 3: 基盤モデル 28%]
    A --> E[ドメイン 4: 責任ある AI 14%]
    A --> F[ドメイン 5: セキュリティとガバナンス 14%]
```

*図 0.6.4: AIF-C01 V1.1 のドメインウェイト。ドメイン 2 と 3 は合わせて生成 AI と基盤モデルアプリケーションをカバーし、スコア付きコンテンツの半数以上を占めます。*

基盤モデルと生成 AI を合わせると試験の半分以上をカバーしており、これらのトピックがエンタープライズ AI 業務の中心にいかに急速に移行したかを反映しています。試験では以下の能力が問われます。

- AI/ML および生成 AI の概念と AWS サービスへの理解を示す
- 異なる AI テクノロジーの適切なユースケースを評価する
- AI ソリューションの実装について根拠ある判断を下す
- 責任ある AI の実践とガバナンスの原則を適用する

### 対象者

理想的な受験者は、AWS 上の AI/ML テクノロジーに約 6 か月間触れた経験を持ちます。AI/ML ソリューションを利用することに慣れている必要がありますが、自ら構築することは求められていません。Amazon EC2、Amazon S3、AWS Lambda、Amazon Bedrock、Amazon SageMaker AI などの**コア AWS サービス**の実践的な知識が必要です。[^006005]

また、**AWS 責任共有モデル**、AWS Identity and Access Management（IAM）、および AWS サービス価格モデルの実践的な理解も求められます。

さまざまな職種の専門家がこの認定から異なる形で恩恵を受けられます。

*表 0.6.1: AWS 認定 AI プラクティショナーから恩恵を受ける役割。*

| 役割カテゴリ | 主なスタッフ | 主なメリット | 主な活動 |
|-------------|------------|------------|----------|
| ビジネス意思決定者 | プロジェクトマネージャー、ビジネスアナリスト、経営幹部 | 戦略的計画と評価能力 | AI イニシアティブの評価、実現可能性の評価、採用ロードマップの策定 |
| テクノロジー専門家 | IT スタッフ、クラウドアーキテクト、テクニカルコンサルタント | 技術的統合とサポートの知識 | AI システムのサポート、統合ソリューションの設計、プラットフォーム評価 |
| ドメインスペシャリスト | 業界の専門家、研究専門家、QA スペシャリスト | ドメイン固有の AI 応用の洞察 | 実装のガイド、品質の確保、応用の探索 |
| サポートと運用 | 運用チーム、カスタマーサクセスマネージャー、テクニカルライター | 運用の卓越性とサポート能力 | AI サービスの管理、システムの文書化、トレーニングプログラムの開発 |

この認定では、AI/ML モデルの開発、データエンジニアリングの実装、ハイパーパラメータのチューニング、AI/ML パイプラインの構築、モデルの数学的分析、または完全なガバナンスフレームワークの開発は必要ありません。これらは上位レベルの認定が対象とするスキルです。

### 試験構造とスコアリング

試験には 50 問のスコア付き問題と、AWS が将来のコンテンツ候補を評価するために使用する 15 問のスコアなし問題が含まれています。スコアなし問題は試験全体に分散されており、どの問題かは識別できません。推測によるペナルティはなく、未回答の問題は不正解としてスコアされます。

スコアリングモデルには 4 つの特徴があります。

- 100 から 1,000 の範囲のスケールドスコア
- 最低合格スコア 700
- 補完的スコアリング（各セクションを個別に合格する必要はなく、試験全体のみ合格が必要）
- 複数の試験形式にわたる難易度の公平性を維持するためのスケールドスコア

スコアレポートには、全体の合否ステータス、スケールドスコア、および強みと弱みを示すセクションレベルのパフォーマンスフィードバックが含まれています。セクションレベルのフィードバックは全般的なガイダンスであり、正確なセクション別成績ではありません。

標準の試験時間は 90 分です。英語を母国語としない受験者は、英語での受験時に「ESL +30」と呼ばれる 30 分の延長を申請でき、合計 120 分になります。

## 試験の問題形式

試験では 4 つの問題形式が使用されます。形式を事前に理解しておくと、時間配分がしやすくなり、当日の戸惑いを防げます。

### 多肢選択問題

多肢選択問題は、シナリオまたは概念を 4 つの選択肢（正解 1 つと誤答 3 つ）とともに提示します。誤答は一般的な誤解を反映しており、表面的な知識だけでなくトピックの深い理解を問うよう設計されています。

例：

```
機械学習モデルを大規模に構築、トレーニング、
デプロイするための完全マネージド環境を提供する AWS サービスはどれですか？

A) Amazon EC2     - 仮想サーバーを提供するが ML の手動セットアップが必要
B) Amazon S3      - ストレージを提供するが ML 機能はない
C) Amazon SageMaker AI - ML ワークフロー向けの専用マネージドサービス
D) Amazon Redshift - ネイティブ ML 機能のないデータウェアハウスサービス

正解: C
```

不正解の選択肢は、ML ワークフローに何らかの形で関わっているものの、完全なマネージド ML エクスペリエンスを提供しないサービスです。

### 複数回答問題

複数回答問題は、5 つ以上の選択肢から 2 つ以上の正解を選ぶ形式です。得点を得るにはすべての正解を選択する必要があります。部分点はありません。

```
Amazon SageMaker Studio が提供する機能はどれですか？（2 つ選択）

A) ML のための統合開発環境（IDE）
B) 自動モデルデプロイとモニタリング
C) トレーニング用の生コンピュートキャパシティ
D) データセット用のオブジェクトストレージ
E) リレーショナルデータベース管理

正解: A、B
```

複数回答問題に取り組む際のポイント：

1. 問題を注意深く読み、必要な回答の数を正確に確認する。
2. 各選択肢を比較する前に独立して評価する。
3. 指定された数の回答を正確に選択したことを確認する。
4. 部分点がないため、すべての選択が正確であることを確認する。

### 順序付け問題

順序付け問題は、連続したプロセスへの理解を問います。タスクを完了するために正しい順序に並べる必要がある 3 から 5 つの項目が提示されます。

```mermaid
flowchart TD
    A[1. データ収集] --> B[2. データ処理]
    B --> C[3. モデルトレーニング]
    C --> D[4. モデル評価]
    D --> E[5. デプロイメント]
```

*図 0.6.5: 順序付け問題の例として使用される標準的な ML ワークフロー。各ステップは前のステップに依存しており、順序は標準的な慣行を反映しています。*

順序付け問題では以下の点を押さえておくことが重要です。

- ステップ間の依存関係
- AWS サービスの要件と前提条件
- 業界標準のワークフロー
- AWS のベストプラクティス

### マッチング問題

マッチング問題では、2 つのリスト内の項目を対応付けることが求められます。通常、3 から 7 つのプロンプトと対応する説明のリストが提示され、各プロンプトを正しい説明と結びつけます。

典型的なマッチング問題：

```
AWS AI/ML サービスとその主な機能を一致させてください。

プロンプト：
1. Amazon Bedrock
2. Amazon SageMaker Canvas
3. Amazon Comprehend
4. Amazon Rekognition

説明：
A. コードなしの ML モデル構築と推論
B. 自然言語処理とテキスト分析
C. 基盤モデルへのアクセスとデプロイ
D. コンピュータビジョンと画像・動画分析

正解の一致: 1-C, 2-A, 3-B, 4-D
```

マッチング問題に取り組む際のポイント：

1. 対応付けを始める前に両方のリストのすべての項目を注意深く読む。
2. 明らかなペアを最初に確定し、残りを消去法で絞り込む。
3. 残りの難しいペアには消去法を活用する。
4. AWS の知識に照らして各ペアを確認する。

## 試験準備のヒント

### 時間管理

多くの受験者にとって、効果的な時間管理は純粋な知識と同じくらい重要です。実践的なガイドライン：

1. 開始前に問題数と試験時間を確認する。
2. 最初の通し解答では問題あたり約 80 秒を目標とする。
3. 1 問に 2 分以上費やさない。
4. 難しい問題にフラグを付け、一通り解き終えた後で見直す。
5. 最後に少なくとも 5 から 10 分のレビュー時間を確保する。

英語を母国語としない場合、AWS は調整として 30 分の追加試験時間を申請できます。申請は試験予約前に AWS Certification アカウントから行う必要があり、承認されると同アカウントでスケジュールするすべての AWS 試験に適用されます。

### 重点分野

試験は暗記よりも実践的な応用を重視しています。特に力を入れるべき分野：

- エージェント型 AI、RAG、MCP を含むコア AI/ML の概念と用語
- ビジネス課題に対する適切な AI サービスの選択
- 特に Amazon Bedrock と AgentCore ファミリーの AWS サービスの機能と制限
- バイアス、公平性、透明性、および説明可能性を含む責任ある AI の原則
- Amazon Bedrock Guardrails と AI に対する AWS 責任共有モデルを含むセキュリティ

問題は定義を暗唱できるかではなく、現実的なシナリオで知識を応用できるかを問います。

| ドキュメント | 技術ガイドとホワイトペーパー | 深い技術的知識の構築 |
| ハンズオンラボ | AWS コンソールの実践演習 | 実際の経験とスキル確認 |

AIF-C01 については、AI/ML の基礎、GenAI と FM のドメイン、そして V1.1 で追加されたエージェント型 AI の内容に重点を置いてください。**Amazon Bedrock**、モデルプレイグラウンド、および **Amazon Bedrock AgentCore** でのハンズオン時間は、基礎が整った後の学習投資として最も高い効果をもたらします。

## まとめ

AWS 認定 AI プラクティショナー認定は、AWS 上の現代 AI に関する本質的な知識を検証します。クラシカル ML、生成 AI、エージェント型 AI、そしてますます重視される責任ある AI の実践がその対象です。AI を活用するビジネスアナリスト、プロダクトマネージャー、およびその他の専門家向けに設計されたこの認定は、以下の能力を証明します。

- AI テクノロジーの採用について根拠ある判断を下す
- AI イニシアティブについて技術チームとコミュニケーションを取る
- 適切な課題に対して適切な AI サービスを選択する
- 組織内で責任ある AI の実践を適用する
- AWS 上で急速に進化する AI の状況を把握し続ける

この認定を取得することで、ビジネス価値に焦点を当てながら AI を理解するための基盤が確立されます。より多くの組織が Amazon Bedrock、Amazon Bedrock AgentCore、Amazon SageMaker AI、Kiro などのサービスを通じて AI の実験から本番運用へと移行するにつれて、この認定はますます価値を持つものとなります。

AWS 認定は、AI が主流のビジネス運営に浸透するにつれてクラウドの専門知識を証明し、キャリア成長を加速するパスであり続けます。AWS 認定 AI プラクティショナー認定は、急速な AI 採用期において技術的役割とビジネス的役割を橋渡しする存在であり、V1.1 アップデートにより試験内容が 2026 年の市場の実情に即して更新されました。
